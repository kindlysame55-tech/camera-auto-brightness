# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User approved static HTML/CSS/JavaScript, deployed with GitHub Pages. The desktop product remains Python/Tkinter on Windows.

## Users

Ordinary Windows users evaluating webcam-based automatic brightness and downloading a portable ZIP.

## Product Purpose

Explain the software in Chinese and English, show its real interface, and guide visitors through download, extraction and launching start-camab.exe.

## Capabilities and Constraints

Windows brightness adjustment using camera-based light estimation, WMI and compatible DDC/CI displays. Gradual automatic transitions, immediate manual control, calibration, pause and system tray. UI currently Chinese. Camera images processed locally; no normal image saving or upload. Device compatibility varies. No license selected; do not invent one. No claims of medical benefit, power savings, user counts or independent benchmarks.

## Evidence on Hand

Source and tests under src/camab and tests. Main UI screenshot docs/images/main.png uses illustrative diagnostic state. Windows portable artifact is built locally. Synthetic demonstrations must be explicitly labeled.

## Product Principles

Make downloading and launching obvious. Explain hardware limits honestly. Preserve working desktop software. Offer equivalent Chinese and English website content.
