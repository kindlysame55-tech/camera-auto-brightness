让屏幕，跟着光走。

用摄像头感知环境光，平滑调节 Windows 屏幕亮度。

Camera Auto Brightness 通过电脑摄像头感知环境光照，自动调节屏幕亮度。支持手动接管与校准，让日常办公与学习少一次来回调节。

Windows 10/11 · 64 位 · 解压即用

环境变亮

拖动体验明暗变化。仅改变网页预览，不会控制你的屏幕。

从下载到自动调光，三步就好。

Get started in three steps.

  1. 下载 ZIP

    获取 Windows 便携版压缩包。

  2. 解压文件

    完整解压，保持两个 EXE 在同一文件夹。

  3. 双击启动

    start-camab.exe
    打开界面，按需校准。

把调节交给软件，把控制留给你。

柔和变化

自动亮度以小步过渡，配合平滑与迟滞，减少突然跳变。你可以在设置里调整过渡速度。

随时接管

拖动软件里的亮度滑块立即调节。默认接管 60 秒，之后恢复自动；也可以暂停或重新校准。

画面留在本机

正常运行只在本机分析摄像头画面，不保存或上传图像。无有效画面时保持当前亮度。

适配你的设备

内屏使用 WMI，兼容外接屏使用 DDC/CI。摄像头估算并非专业照度测量，建议根据实际环境完成校准。

你可能想知道的。

我的电脑可以用吗？

需要 Windows 10/11 64 位、可用摄像头，以及支持软件调光的显示器。外接显示器需在菜单中开启 DDC/CI；转接器、扩展坞和显示器型号会影响兼容性。

需要安装 Python 吗？界面支持英文吗？

便携 ZIP 已包含运行环境，无需安装 Python。网站与仓库说明为中英双语，桌面软件界面和多数命令行提示目前使用中文。

为什么没有自动调亮度？

先检查“仅模拟调光”是否开启、自动模式是否暂停，以及手动接管倒计时是否结束。再确认摄像头有有效画面，查看界面设备提示。仓库 README 提供完整自检命令和排查说明。

关闭窗口后，程序还在运行吗？

通常会收起到 Windows 托盘继续运行。想彻底退出，请使用托盘菜单中的退出选项。配置与日志保存在当前用户的本地应用数据目录。
